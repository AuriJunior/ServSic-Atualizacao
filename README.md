# ServSic — pacote de atualizacao

Repositorio **publico exclusivo** para distribuir o pacote compilado do ServSic (`AtServsic.zip`).

## O que ha aqui

- **Somente binarios** publicados em [Releases](../../releases) (sem codigo-fonte).
- Mesmo modelo do FTP Compuserve: `AtServsic.zip`, `AtServsic_<versao>.zip`, `manifest.json`, `PathNotes.txt`, `NotasVersao.txt`, `versao.txt`.

## URLs estaveis (ultima versao)

Substitua `AuriJunior` pelo usuario/org deste repositorio:

- Manifesto: `https://github.com/AuriJunior/ServSic-Atualizacao/releases/latest/download/manifest.json`
- Pacote fixo: `https://github.com/AuriJunior/ServSic-Atualizacao/releases/latest/download/AtServsic.zip`
- Notas: `https://github.com/AuriJunior/ServSic-Atualizacao/releases/latest/download/NotasVersao.txt`

## Privacidade

Este repositorio **nao** contem fontes `.pas`, `.dfm`, `.dpr` nem projetos Delphi.
O historico git da pasta raiz fica minimo (README / .gitignore). Os ZIPs ficam apenas nos Releases (CDN do GitHub).

## Publicacao

Feita pela Compuserve via `PublicarAtualizacaoServSic.ps1` (FTP + Google Drive + este GitHub).
